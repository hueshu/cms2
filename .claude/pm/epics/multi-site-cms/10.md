# Task: 站点管理功能

## Description
实现完整的站点CRUD API，包括多租户隔离逻辑和域名绑定配置。为CMS系统提供核心的站点管理能力，确保多站点之间的数据完全隔离，支持自定义域名绑定。

## Acceptance Criteria
- [ ] 实现站点创建API (POST /api/sites)
- [ ] 实现站点查询API (GET /api/sites, GET /api/sites/:id)
- [ ] 实现站点更新API (PUT /api/sites/:id)
- [ ] 实现站点删除API (DELETE /api/sites/:id)
- [ ] 实现多租户数据隔离机制
- [ ] 实现域名绑定配置功能
- [ ] 实现站点状态管理 (启用/禁用)
- [ ] 所有API支持分页和筛选

## Technical Details
- **数据模型设计**：
  - sites表：id, name, domain, custom_domain, status, config, created_at, updated_at
  - 使用siteId作为所有数据的隔离键
- **API端点设计**：
  - 遵循RESTful规范
  - 统一的错误处理和响应格式
  - 支持查询参数过滤和排序
- **多租户隔离**：
  - 中间件级别的siteId注入
  - 数据库查询自动添加siteId过滤条件
  - KV存储使用siteId前缀
- **域名绑定**：
  - 支持子域名和自定义域名
  - DNS验证机制
  - SSL证书自动配置
