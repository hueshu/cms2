# Task: 内容管理系统

## Description
构建完整的内容管理系统，包括文章CRUD操作、Markdown渲染和标签系统。为每个站点提供独立的内容管理能力，支持富文本编辑、分类标签和SEO优化。

## Acceptance Criteria
- [ ] 实现文章创建API (POST /api/articles)
- [ ] 实现文章查询API (GET /api/articles, GET /api/articles/:id)
- [ ] 实现文章更新API (PUT /api/articles/:id)
- [ ] 实现文章删除API (DELETE /api/articles/:id)
- [ ] 集成Markdown渲染引擎
- [ ] 实现标签CRUD系统
- [ ] 实现文章-标签关联管理
- [ ] 支持文章状态管理 (草稿/发布/归档)
- [ ] 实现文章搜索和过滤功能

## Technical Details
- **数据模型设计**：
  - articles表：id, site_id, title, slug, content, status, author, meta_title, meta_description, created_at, updated_at, published_at
  - tags表：id, site_id, name, slug, description
  - article_tags表：article_id, tag_id (多对多关联)
- **Markdown处理**：
  - 使用marked.js进行服务端渲染
  - 支持代码高亮和表格
  - 自动生成目录
  - 图片懒加载优化
- **标签系统**：
  - 标签自动建议
  - 热门标签统计
  - 标签层级支持
- **内容优化**：
  - 自动slug生成
  - SEO meta信息管理
  - 内容摘要自动提取
