## 🚀 快速开始

### 登录系统

1. 打开管理后台：`https://your-domain.com/admin`
2. 输入您的邮箱和密码
3. 点击"登录"按钮

### 创建第一个站点

1. 登录后，点击左侧菜单中的"站点管理"
2. 点击"创建站点"按钮
3. 填写站点信息：
   - **站点名称**: 您的站点名称
   - **域名**: 您的域名（如：myblog.com）
   - **描述**: 站点简短描述
4. 配置SEO设置：
   - **SEO标题**: 站点的SEO标题
   - **SEO描述**: 站点的SEO描述
   - **关键词**: 相关关键词（用逗号分隔）
5. 点击"保存"完成创建

### 发布第一篇文章

1. 在站点列表中，点击您刚创建的站点
2. 进入站点后，点击"文章管理"
3. 点击"新建文章"
4. 填写文章信息：
   - **标题**: 文章标题
   - **内容**: 文章内容（支持Markdown格式）
   - **摘要**: 文章摘要
   - **标签**: 相关标签
5. 在SEO设置中优化：
   - **SEO标题**: 文章的SEO标题
   - **SEO描述**: 文章的SEO描述
6. 将状态设置为"已发布"
7. 点击"保存"完成发布

```xml
  <url>
    <loc>https://example.com/articles/first-article</loc>
    <lastmod>2024-01-01</lastmod>
    <changefreq>weekly</changefreq>
```

### SEO最佳实践

#### 标题优化

**好的标题示例**
```
✅ "React Hooks完全指南：从入门到精通"
✅ "2024年最佳SEO策略：提升网站排名的10个技巧"
✅ "JavaScript性能优化：减少加载时间50%的方法"
```

**避免的标题**
```
❌ "文章"
❌ "新产品发布!!!!!!"
❌ "点击这里了解更多信息"
```

#### 描述优化

**好的描述示例**

#### 关键词策略

**关键词选择原则**
1. 相关性：与内容高度相关
2. 搜索量：有一定搜索需求
3. 竞争度：难度适中
4. 长尾词：包含长尾关键词

**关键词使用**
- 标题中包含主关键词
- 描述中自然使用关键词
- 内容中适当分布关键词
- 避免关键词堆砌

## 🌐 域名配置

### 域名绑定

#### 添加自定义域名

1. **DNS配置**
   - 登录域名管理面板
   - 添加CNAME记录指向系统域名
   - 等待DNS传播（通常5-30分钟）

2. **系统配置**
   - 在站点设置中添加自定义域名
   - 验证域名所有权
   - 启用HTTPS证书

#### DNS配置示例

**主域名配置**
```
类型    名称    值                      TTL
A       @       192.0.2.1              300
CNAME   www     your-site.pages.dev    300
```

**子域名配置**
```
类型    名称    值                      TTL
CNAME   blog    your-site.pages.dev    300
CNAME   api     your-api.workers.dev   300
```

### SSL证书管理

#### 自动SSL

- 系统自动为绑定的域名申请SSL证书
- 支持Let's Encrypt免费证书
- 自动续期，无需手动操作
- 强制HTTPS重定向

#### 证书状态检查

```bash
# 检查证书状态
curl -I https://yourdomain.com

# 查看证书信息
openssl s_client -connect yourdomain.com:443 -servername yourdomain.com
```

### 多域名管理

#### 域名别名

一个站点可以绑定多个域名：
- 主域名：example.com
- WWW域名：www.example.com
- 子域名：blog.example.com
- 备用域名：example.net

#### 域名重定向

**301重定向配置**
```javascript
// 将www重定向到主域名
if (url.hostname === 'www.example.com') {
  return Response.redirect('https://example.com' + url.pathname, 301)
}

// 将旧域名重定向到新域名
if (url.hostname === 'old-domain.com') {
  return Response.redirect('https://new-domain.com' + url.pathname, 301)
}
```

### 站点管理问题

**Q: 站点创建后无法访问？**
A: 请检查：
1. 域名DNS配置是否正确
2. SSL证书是否已生效
3. 站点状态是否为"启用"
4. 防火墙设置是否正确

**Q: 如何更换站点域名？**
A:
1. 在站点设置中添加新域名
2. 配置新域名的DNS记录
3. 等待SSL证书生效
4. 设置旧域名301重定向
5. 移除旧域名配置

**Q: 站点数据如何备份？**
A: 系统自动进行数据备份，您也可以：
1. 导出所有文章数据
2. 备份站点配置信息
3. 保存自定义设置
4. 定期下载数据库备份
